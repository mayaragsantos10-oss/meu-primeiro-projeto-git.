- Conceito 2: Repositório
É o espaço de armazenamento digital onde ficam guardados
todos os arquivos, pastas e o histórico completo de revisões de um projeto, podendo
ser local (no computador do usuário) ou remoto (na nuvem, como no GitHub).

- Conceito 3: Commit
É o registro definitivo de um conjunto de alterações realizadas nos arquivos
do projeto em um determinado momento. Cada commit funciona como uma foto do
código naquele instante e recebe um identificador único junto a uma mensagem
descritiva.

- Conceito 4: Branch
É uma linha independente de desenvolvimento criada a partir
de um ponto específico do código principal. As branches permitem desenvolver novos
recursos ou corrigir erros de forma isolada, sem afetar a estabilidade da versão
principal do software.

- Conceito 5: Tag
É uma marcação ou rótulo permanente aplicado a um commit específico no
histórico do projeto. As tags são amplamente utilizadas para identificar pontos
importantes, como o lançamento oficial de versões de produção (por exemplo, v1.0.0).
